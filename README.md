# Everybody Codes 2025 - OllieOA

## Goal

Learn Go standard library with the puzzles, even extend some utils of my own that I want

## Instructions

Copy/paste the base quest (`internal/quest/quest00`) and update the name of the folder and `.go` file.

Implement the logic (assuming only one `sample.txt`/`input.txt` per puzzle which may not hold), then run `go run cmd/ec/main.go [-s] <num>` to execute (using the `-s` flag to denote the sample input).

The script will then print out a result for each of the three parts and the elapsed time.
